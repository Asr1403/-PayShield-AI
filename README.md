# PayShield AI

**AI-Powered Purchase Risk Intelligence and Fraud Detection Platform**

PayShield AI helps users make safer online purchasing decisions through AI-powered risk analysis, transaction intelligence, and live security research.

## Features

- AI-powered purchase risk assessment
- Rule-based fraud detection
- Transaction history and analysis
- Live security research using Tavily
- Security alerts and recommendations
- Smart spending analytics
- PayPal Sandbox integration
- Razorpay Test Mode integration
- User authentication with JWT and HTTP-only cookies

## Technology Stack

**Frontend:** React.js, Vite, JavaScript, CSS

**Backend:** Node.js, Express.js

**Database:** MongoDB

**AI and Research:** Groq API, Tavily Search API

**Payments:** PayPal Sandbox, Razorpay Test Mode

**Authentication:** JWT, bcryptjs

## Project Structure

- `client/` — React frontend application
- `server/` — Express backend application

## Getting Started

1. Clone this repository.
2. Install dependencies inside both `client` and `server`.
3. Configure your environment variables in `server/.env`.
4. Start the backend server.
5. Start the frontend development server.

Use your own API credentials and never commit environment files or secrets.

## Security Notice

PayShield AI provides advisory risk assessments. An AI-generated risk score does not prove that a merchant or transaction is fraudulent.

Payment integrations use testing environments.

## Project Purpose

To combine artificial intelligence, transaction intelligence, and live security research to improve awareness of online payment risks.
